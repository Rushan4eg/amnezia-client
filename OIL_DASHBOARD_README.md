# 🛢 НефтеМониторинг — демо-макет дашборда добычи нефти и МГРП

Одностраничный HTML-макет (`oil-extraction-viz.html`) платформы мониторинга добычи нефти
и многостадийного гидроразрыва пласта (МГРП). Открывается в браузере без сборки —
все зависимости подтягиваются с CDN.

**Все данные синтетические, модели упрощённые и учебные.** Макет подходит как основа для
курсовых/дипломных работ по разработке нефтяных месторождений и как каркас для реального
инструмента (замените генераторы данных на загрузку своих).

## Запуск

Откройте `oil-extraction-viz.html` в любом современном браузере (нужен интернет для CDN).
Тема переключается кнопкой «🌓 Тема» в шапке и следует системной по умолчанию.

## Вкладки

| Вкладка | Что внутри |
|---|---|
| **Добыча нефти** | KPI-плитки, добыча по регионам (линии), структура по способам эксплуатации (стек), крупнейшие месторождения (бары) |
| **Трещины МГРП** | Кривая ГРП (давление/расход/пропант, ISIP), карта микросейсмических событий, приток по стадиям (трассеры), прогноз полудлины с интерактивными параметрами дизайна |
| **3D и SVG** | ECharts GL: 3D-облако микросейсмики, поверхность кровли пласта, 3D-бары добычи, траектория ствола с портами, глобус месторождений мира; SVG-рендер: спидометр давления, добыча «каплями» |
| **Калькулятор ГРП** | 1) геометрия трещины PKN/KGD, 2) оптимум Unified Fracture Design (Синко-Лей), 3) NPV-оптимум числа стадий (Арпс), 4) подбор пропанта по напряжению смыкания |
| **DFIT-анализ** | Загрузка CSV кривой падения давления, G-функция Нолте с производной, автоопределение давления смыкания методом касательной, диагностики √t и log-log |
| **Пультовая ГРП** | Стриминговая имитация стадии с тремя сценариями, анализ Нолте—Смита, движок алертов (риск СТОПа), журнал событий, выгрузка CSV |
| **Сравнение скважин** | Паспорт куста, профили добычи, удельная эффективность (на стадию / на тонну пропанта), постадийное сравнение притока двух скважин |

Кнопка **«Отчёт PDF»** в шапке собирает печатную сводку по всем расчётным модулям
(геометрия, UFD, NPV, DFIT, куст) с графиками — сохраняется в PDF через диалог печати.

## Формат CSV для DFIT

Две колонки: `время от остановки, мин` и `давление, МПа`. Разделитель — запятая,
точка с запятой или таб; десятичная запятая допускается; строка заголовка не обязательна.

```
t;P
0.2;51.94
0.4;51.80
...
```

## Технологии и модели

- **UI:** Bootstrap 5.3 (навбары, сетка, светлая/тёмная тема через `data-bs-theme`)
- **Графики:** Apache ECharts 5.5 + ECharts GL 2.0 (WebGL), SVG-рендерер для спидометра
  и пиктограмм; карта мира — GeoJSON из пакета `echarts@4`
- **Модели (учебные):** ширина трещины — решения без утечек (Нордгрен / Гертсма—де Клерк),
  полудлина — материальный баланс с эффективностью жидкости; оптимум геометрии — UFD с
  псевдоскином Синко-Лея и пределом дренирования; экономика — гиперболика Арпса с
  интерференцией стадий (q ~ N^α); смыкание — метод касательной на G-функции Нолте;
  режимы распространения — наклон Нолте—Смита в log-log; проводимость пропанта —
  экспоненциальный спад с напряжением смыкания
- **Доступность:** у 2D-графиков есть табличные представления, палитра проверена на
  различимость при цветовой слепоте и контраст к поверхности

## Ограничения

- 3D-сцены требуют WebGL.
- Реальные инженерные решения требуют симулятора ГРП и калибровки на промысловые данные —
  числа макета иллюстративные.
